# Guia rápido — Hipermídia educacional

## Estrutura
- Qual é o ponto de entrada?
- Existe um percurso principal compreensível?
- O estudante sabe onde está?
- É possível retornar a um ponto de referência?

## Links
- O texto do link informa o destino?
- Cada link tem função real?
- Há links redundantes ou excessivos?
- Links externos são distinguidos quando necessário?

## Mídias
- Cada mídia contribui para compreender algo?
- Existe alternativa textual quando necessária?
- O conteúdo continua compreensível sem efeitos decorativos?

## Legibilidade e acesso
- Contraste e tamanho de texto são adequados?
- A navegação funciona por teclado quando aplicável?
- O layout funciona em tela pequena?
- O conteúdo respeita usuários que preferem movimento reduzido?

## Aprendizagem
- A hipermídia oferece uma tarefa, pergunta ou objetivo de navegação?
- O estudante produz alguma evidência de compreensão?
- Há orientação ou feedback para avançar?

## Autoria e uso de IA

Antes de recorrer a IA, produza o mapa de navegação e defina os nós principais da hipermídia. Se a ferramenta for utilizada para sugerir texto, organização, código ou alternativas de navegação, registre o uso e revise criticamente o resultado.

O estudante deve conseguir explicar a estrutura, os links, as escolhas de mídia e qualquer trecho de código ou conteúdo incorporado ao protótipo. Material que não possa ser explicado será considerado evidência insuficiente de aprendizagem.
